# Plan: 배치와 AES67 연결을 Kodi UI에서

2026-11-18. 사용자 승인.

## 정한 것

- 배치는 SECS 2R이 다루는 프리셋에서 고르기만 한다. 실제 위치와 거리는 SECS 보정이 맞춘다. 배치 파일은 애드온에서 빼고 명령줄·설정 파일에만 남긴다.
- 수신기는 Dante 장비(AES67 모드)다. 자동 연결은 netaudio의 `netaudio-core`(Unlicense, Dante 프로토콜 역분석)로 한다. Dante 장비 없이는 검증할 수 없으므로 마지막에 한다.

## 작업

- [x] **U1. 배치 프리셋만.** 애드온에서 배치 파일 항목을 빼고, SECS 역할로 옮길 수 있는 프리셋만 남긴다(22.2 제외).
  - Verify: 남긴 프리셋마다 `manual::topology`가 통과하는 단위 시험
- [ ] **U2. 채널→스트림 배정.** 송출기가 `--streams FILE`(이름, 멀티캐스트 주소, 출력 채널 이름 최대 8개)을 받는다. 없으면 지금처럼 8채널씩 보낸다. 출력에 없는 이름은 알리고 건너뛴다(보정 모드를 바꾸면 출력 이름이 바뀌므로 서비스를 멈추지 않는다). 애드온에 스트림 편집 대화상자를 넣는다.
  - Verify: 송출기 E2E(이름 붙은 스트림 두 개, 채널 순서·SDP 이름), 애드온 단위 시험
- [ ] **U3. 상태 화면.** 송출기 `status` 명령(JSON 한 줄): 그랜드마스터, 스트림별 채널·주소, 재생 중 여부, 송출 오류 수, 볼륨, 지연. 애드온 대화상자.
  - Verify: 송출기 E2E로 `status` 응답
